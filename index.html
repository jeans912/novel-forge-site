你可能想知道的

稿子会被上传吗？

不会自动上传。正文保存在你本机；只有你主动点 AI 生成时才发送对应内容， 并且可以在「AI 授权」里设成「禁止云端」，或开启「脱敏」（人名地名换成代号）。

没有显卡能用吗？

能。写作、审计、导出全部可用；视觉小说有「模板模式」，用内置素材直接出片。 想要 AI 生图可以接本机 ComfyUI，或填云端 API Key。

AI 生成要额外花钱吗？

要。1 张图 = 1 点，点数包 ¥29 / 150 张、¥45 / 300 张；也可以用自己的 API Key，成本自付。 模板模式不扣点。

换电脑怎么办？

激活码绑定机器。换机时联系作者迁移（需提供旧机器码与新机器码）。

为什么 Windows 提示"未知发布者"？

安装包暂未做代码签名。可以点「更多信息 → 仍要运行」；我们正在处理证书。
