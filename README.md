# 小说工坊 NovelForge

把小说，变成能玩的东西。

一个 Windows 桌面写作工具：写小说、查设定冲突、一键生成可玩的视觉小说。

## 它能做什么

- **写**：章纲（目标 / 阻力 / 转折 / 钩子 / 推进线）→ 正文，AI 不偷写
- **查**：行内一致性提示（伤口、发色、重复句）+ 审计报告 + 审查历史
- **存**：多目标备份、WebDAV、从备份恢复、AI 调用可审计
- **转**：正文 → 剧本 → 立绘/场景 → 可玩的网页版视觉小说（或 Ren'Py 工程）
- **出**：EPUB、投稿包、手机阅读版、写作数据卡

## 这个仓库是什么

本仓库只存放**产品介绍页**（静态站点），用于对外展示与创作者认证。

- 站点源文件：`index.html`、`img/`、`video/`、`licenses/`
- 安装包不放这里（体积原因），请在 Releases 或官网下载

## 技术栈（产品本体）

Python + PySide6（Qt6）桌面应用；本地 ComfyUI / 云端 API 生图；
本地优先存储，稿件默认不出本机。
